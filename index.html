支持哪些输入？抓包数据怎么填？
Hex 支持 82 A2 6F 6B C3、连续十六进制、0x82, 0xa2、\x82\xa2；每个字节必须写满两位。支持行尾 \ 续行。十进制数组使用 [130, 162, 111, 107, 195]。Base64 请手动选择对应格式，避免将纯字母数字误判为 Hex。
“导入二进制”直接读取文件的原始字节；文本形式的 Hex / Base64 请复制到输入框。抓包时只复制负载中的字节，不要包含偏移地址、时间戳或 ASCII 列。已知包头或校验尾长度时可设置“跳过包头”和“跳过包尾”，两者作用于整段输入，跳过后至少需保留 1 字节。连续消息模式把剩余数据中的各条消息放进一个 JSON 数组，不会逐条去除包头包尾，也不会自动重组蓝牙分包。

      
整数、二进制和扩展类型如何转换？
超过 ±9007199254740991 的整数输出为十进制字符串，保留全部数字。二进制输出为 {"$binary":"十六进制"}；未知扩展为 {"$ext":{"type":类型,"hex":"…"}}；时间戳为 {"$timestamp":{"seconds":"秒","nanoseconds":纳秒}}，保留纳秒精度。
存在非字符串键或重复键的 Map 使用 {"$map":[[键,值],…]}，保留键值对。NaN、Infinity、-Infinity 和负零输出为 {"$float":"…"}。这些是本工具约定的 JSON 表示，特殊转换会显示提示。选中右侧字段名或值，左侧会以黄色定位对应字节（包括类型和长度标记），支持拖选、双击和键盘选择；Base64 按覆盖这些字节的编码字符定位。结构错误会在结果区标红；数组长度推断仅是诊断候选，不会修改输入，需对照协议确认。没有协议字段定义时，无法识别所有语义错误；64 KiB 以上数据仅显示基础错误。最多支持 128 层嵌套、200000 个值。
